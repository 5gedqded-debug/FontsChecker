# FontsChecker

Android-приложение для просмотра шрифтов. Показывает, для каких языков создан шрифт.

## Как работает

1. **Стартовый экран**: кнопка «Выбрать шрифт» открывает системный выбор файла (любое расширение).
   Шрифт также можно открыть из файлового менеджера (VIEW-интент).
2. **Экран просмотра**: сверху карусель кнопок-переключателей с языками, которые есть в шрифте
   (шрифт считается поддерживающим язык, если в нём есть **все** буквы алфавита этого языка).
   Для выбранного языка показываются алфавит, цифры и пример текста размерами 12–60 sp.
   Дополнительно есть вкладки «123 #?!» (символы) и «Свой текст» (ввод произвольного текста).
3. Кнопка «i» в шапке показывает название шрифта, формат, число символов Unicode и список языков.

Языки: English, Русский, Українська, Беларуская, Български, Српски, Қазақша, Ελληνικά, Deutsch, Français,
Español, Português, Italiano, Polski, Čeština, Română, Magyar, Türkçe, Svenska, Dansk, Tiếng Việt,
العربية, עברית, ไทย, हिन्दी, ქართული, Հայերեն, ひらがな, カタカナ, 한국어, 简体中文, 繁體中文.
Новые языки добавляются в `Languages.kt` (название, пример, алфавит).

Форматы: TTF, OTF, TTC, WOFF. WOFF2 пока не поддерживается (нужен Brotli).
Для китайского проверяется только набор символов из примера, а не весь набор иероглифов.

## Сборка

Сборка только вручную: **Actions → Build APK → Run workflow**. Готовый APK появится в артефактах запуска
(`FontsChecker-apk`).

APK подписывается постоянным тестовым ключом `app/test-signing.jks`
(пароль `fontschecker`, alias `test`). Ключ лежит в репозитории специально, чтобы все сборки имели
одну подпись и обновлялись друг поверх друга. **Для публикации в магазинах его использовать нельзя.**

Локально: `gradle assembleRelease` (нужны JDK 17 и Android SDK).
